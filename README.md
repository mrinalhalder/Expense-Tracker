
# Expense Tracker

A personal finance dashboard built with HTML, CSS, and Vanilla JavaScript.

## About the Project

Expense Tracker is a frontend project designed to practice JavaScript fundamentals by building a personal finance management interface.

The initial version contains the basic HTML structure and responsive CSS layout. JavaScript functionality will be added incrementally.

## Current Features

- Dashboard layout
- Income, expense, and balance summary cards
- Transaction form UI
- Recent transactions table
- Search and category filter UI
- Monthly summary and chart placeholders
- Responsive layout for mobile and desktop

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (planned)

## Learning Goals

- DOM manipulation

- Form validation

- Responsive web design
